# 智愈云互联网医疗协同平台

该项目提供患者端与医生端的互联网医院示例，包含前后端联动的数据展示。

## 功能概览
- 患者端：预约管理、健康指标、护理计划与在线医生服务。
- 医生端：今日排班、患者队列、重点预警与诊疗绩效。
- 后端 API：提供患者端与医生端实时数据。

## 本地运行

```bash
npm install
npm start
```

访问：
- 首页：`http://localhost:3000/`
- 患者端：`http://localhost:3000/patient.html`
- 医生端：`http://localhost:3000/doctor.html`
